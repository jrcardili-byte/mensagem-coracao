# Uma Mensagem para o Seu Coração

Sorteador de mensagens de acolhimento, autoestima e reflexão para turmas do 6º ao 9º ano.

- **Link:** https://jrcardili-byte.github.io/mensagem-coracao/
- **No celular:** abra o link e use "Adicionar à tela inicial". Depois da primeira visita, funciona sem internet.
- **No computador:** abra o link ou o arquivo `index.html`.

Instruções completas em `COMO-USAR.txt`.

## Para atualizar o app

Edite `index.html` e troque a versão em `sw.js` (`mensagens-v1` → `mensagens-v2`) para os celulares baixarem a versão nova. A publicação é automática a cada envio para `main`.
